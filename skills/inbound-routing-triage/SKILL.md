# Inbound Routing Triage

## Overview
This skill categorizes incoming email traffic, separates critical correspondence from newsletters or spam, and routes messages to target mailboxes.

## Capabilities
- Inspects SPF, DKIM, and DMARC verification headers.
- Classifies emails into standard folders (Inbox, Spam, Archive, Trash).
- Flags high-priority messages requiring immediate user attention.
