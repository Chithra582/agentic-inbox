# Autonomous Reply Drafting

## Overview
This skill composes professional draft replies for inbound messages while enforcing strict human approval boundaries before dispatch.

## Capabilities
- Formulates markdown and HTML email responses tailored to sender tone.
- Constructs formatted quoted reply blocks citing previous messages.
- Staged completed drafts directly into the mailbox's Drafts folder for user review.
